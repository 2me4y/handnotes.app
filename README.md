# handnotes.app 📓✍️

Современное веб-приложение для генерации фотореалистичных рукописных конспектов прямо на страницах тетрадей.

---

## 🚀 Основные возможности

### 1. 📷 Загрузка своего фото тетради и пресеты
- **Своё фото тетради**: загружайте фотографии своих тетрадных листов (в клетку, линейку, с рисунками и т.д.) через кнопку выбора или перетаскиванием (Drag & Drop) прямо на лист.
- **Встроенные реалистичные пресеты**:
  - Тетрадь в клетку (5×5 мм) с классической красной линией полей;
  - Тетрадь в линейку с полями;
  - Косая линейка для прописей;
  - Чистый крафтовый/винтажный лист.
- **Инструменты коррекции фото**:
  - **Яркость (отбеливание)**: удаляет тени от смартфона при съёмке;
  - **Контраст**: делает клетки и строки чёткими;
  - **Насыщенность**: возможность обесцветить или сделать цвета сочнее;
  - **Поворот фото**: свободный угол от -180° до +180° и быстрые кнопки 90° для выравнивания криво сфотографированного листа;
  - **Масштаб (зум)**: подгонка размера клеток под нужный масштаб;
  - **Смещение по осям X и Y**: точное позиционирование тетрадного листа.

### 2. ✍️ Шрифты и реалистичный почерк
- **Загрузка своего шрифта**: поддержка файлов `.ttf`, `.otf`, `.woff`, `.woff2`. Шрифт мгновенно подключается в браузере.
- **Базовые рукописные шрифты с поддержкой русского языка**:
  - `Caveat` (беглый студенческий почерк);
  - `Marck Script` (аккуратный каллиграфический);
  - `Bad Script` (школьная шариковая ручка);
  - `Neucha` (печатный рукописный);
  - `Shantell Sans` (современный рукописный);
  - `Kelly Slab` (строгий блочный);
  - `Pangolin` (мягкий округлый);
  - `Comfortaa` и `Kurale`.
- **Полная регулировка текста**:
  - **Размер шрифта** (px);
  - **Наклон почерка (курсив)** (от -25° влево до +35° вправо);
  - **3D Перспектива и ракурс (Трапеция)**:
    - *Трапеция (Верх уже / Низ шире)*: от -60% до +60% — подстраивает текст под фото тетради, снятое на столе под углом;
    - *Поворот всего текста*: свободное вращение от -45° до +45° по углу наклона линий тетради;
    - *Наклон строк (Скос вверх/вниз)*: от -15° до +15°;
    - *Боковая перспектива (Сдвиг)*: от -40% до +40%;
  - **Межстрочный интервал** (для идеального попадания в клетку или линейку);
  - **Межбуквенный интервал**;
  - **Толщина ручки** (Обычная, Средняя, Жирная);
  - **Цвета чернил**: Классическая синяя, Тёмно-синяя, Чернильная фиолетовая, Чёрная гелевая, Красная паста, Зелёная ручка + палитра любого кастомного цвета;
  - **Плотность нажима чернил** (прозрачность ручки);
  - **Эффект "Живой почерк" (Jitter)**: реалистичные микро-колебания строк по вертикали, вариация угла наклона отдельных букв и неравномерность нажима.
  - **Перемещение текста мышью**: просто зажмите текст на листе и перемещайте в любую точку, растягивайте за боковые маркеры!

### 3. 📐 Поля и выравнивание
- Регулировка отступов: сверху, снизу, слева (с учётом красной линии полей) и справа.
- Красная строка (абзацный отступ).
- Режим «Разметка» (кнопка с глазом в шапке) — отображает полупрозрачные направляющие линии для идеального выравнивания текста под строки вашей тетради.

### 4. 🌓 2 темы оформления
- **Светлая тема**: чистый, яркий студийный интерфейс.
- **Тёмная тема**: контрастный тёмный интерфейс для комфортной работы вечером.
- Выбор автоматически сохраняется в браузере (`localStorage`).

### 5. 📄 Многостраничность и экспорт
- Автоматическая разбивка длинного текста на страницы (`Стр. 1 из N`).
- **Скачать PNG**: страница в сверхвысоком разрешении (1400×1980 px).
- **Скачать JPG**: файл умеренного размера для мессенджеров.
- **Сохранить PDF**: экспорт всего конспекта (всех страниц) в единый PDF документ.
- **Печать**: прямая отправка на принтер.

Проект уже запущен локально на:
👉 **http://localhost:5173/**

Для повторного запуска в терминале:
```bash
npm run dev
```

Сборка для продакшена:
```bash
npm run build
```
